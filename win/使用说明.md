# Stop the Slop for Browser 1.5.11 · win 版

轻量包不内置 Node.js。支持插件内查看检测服务状态，以及后台启动和停止服务；不需要保留终端窗口。

## 首次安装 / 从旧版升级

1. 从 [Node.js 官网](https://nodejs.org/) 安装符合自己系统和处理器的 **Node.js 22 或更新版本**。
2. 下载 [最新 Release](https://github.com/LynkHu0/stop-the-slop-for-brower/releases/latest) 的 `-win.zip` 并完整解压。
3. 首次升级请先关闭旧版运行检测服务的终端窗口。双击 `安装本机组件.bat`，完成一次本机组件安装；安装结束后可以关闭窗口。
4. 安装程序会打开永久安装位置的 `extension` 文件夹。Chrome / Edge 扩展管理页开启开发人员模式，移除旧版扩展，再加载安装程序打开的新版 `extension`。
5. 点击插件，在“检测服务”区点击“启动检测服务”。显示“正在运行检测服务”即表示服务已经启动。
6. 在“选择服务 / API设置”中连接自己的 ChatGPT 或保存 DeepSeek Key；插件自动连接本机服务，无需复制连接码。

已安装新版后，日常直接在插件中开关，无需再运行安装文件。初次组件安装会把程序复制到 `%LOCALAPPDATA%\BiliSlop`；以后可删除解压的下载副本，保留永久安装位置。

## 服务开关

- “正在运行检测服务” / “没有运行检测服务”：来自本机服务状态。
- “启动检测服务”：在后台创建检测服务进程；服务停止时也能从插件启动。
- “停止检测服务”：停止接收新任务，取消未开始的排队任务，等待已经发出的模型请求完成后退出。期间显示“正在停止检测服务”。已发出的请求可能已计费用量。
- 关闭插件弹窗或安装终端，不会停止后台服务。退出浏览器后服务仍可运行，电脑重启后需要在插件中再次启动；没有设置开机自启动。
- 若提示组件未安装，重新运行 `安装本机组件.bat` 并确认加载了永久位置的新版扩展。旧版服务占用端口时，先退出旧版终端。

## 数据与权限

首次升级使用固定的扩展标识，因此需要移除旧版再加载。旧扩展的检测缓存与开关设置不会自动迁移；ChatGPT / DeepSeek 的账号配置仍由本机服务保留。插件增加 `nativeMessaging` 权限，仅用于受限的 status/start/stop 本机控制，不允许任意命令或文件访问。

账号、Key 和连接凭据位于 `%LOCALAPPDATA%\BiliSlopData`，不随安装包发布。服务代码依赖已合并，无需手动安装 npm 依赖。卡片结果仍为百分比或“无文案”，评分不能证明创作来源。

## 验证范围

已在隔离本机环境检查后台启动/停止、重复并发启动、原生消息帧、来源限制与受限操作；没有调用模型。Windows 控制流程尚未经过实机验证，插件按钮尚未经过浏览器完整实测。

## 源码开发

`local-server/` 中运行 `npm ci` 安装依赖。`package-release.py` 用于生成无 Node.js 运行环境的轻量包。`native/` 实现浏览器原生通信与后台控制。
