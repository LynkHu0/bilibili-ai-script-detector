# Stop the Slop for Browser · Windows

## 安装

1. 安装 [Node.js](https://nodejs.org/) 22 或更新版本。
2. 从 [Releases](https://github.com/LynkHu0/stop-the-slop-for-browser/releases/latest) 下载 `-win.zip`，解压后运行 `安装本机组件.bat`。
3. 在 Chrome 或 Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载安装程序提示的 `extension` 文件夹：

   `%LOCALAPPDATA%\BiliSlop\extension`

4. 打开插件设置，启动检测服务，连接 ChatGPT 或填写 DeepSeek API Key。

安装完成后，检测服务在后台运行，不需要一直保留终端窗口。

## 更新

下载新版并运行安装本机组件程序，然后在浏览器扩展管理页重新加载插件，刷新 B 站页面。使用 1.5.11 以前的版本升级时，需要移除旧扩展后重新加载上述文件夹。

检测依赖 B 站可读取的字幕，评分仅供参考。设置、隐私和上游说明见[项目首页](../README.md)。
