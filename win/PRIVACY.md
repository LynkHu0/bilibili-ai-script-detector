# 隐私与数据处理说明

适用：Stop the Slop for Browser 1.5.14；更新日期：2026-10-26。本文描述当前源码行为，不替代模型服务商、B站、YouTube、浏览器及系统自身的政策。

## 触发与接收方

| 功能 | 读取/发送的数据 | 接收方与触发条件 |
|---|---|---|
| B站字幕准备 | 视频链接/ID、分P、CID、标题、可用字幕；浏览器登录态用于访问B站接口 | B站及其字幕域名；手动检测或可见卡片自动检测时 |
| B站模型评分 | 字幕前15000字符及检测提示词；模型鉴权凭据 | 所选 OpenAI `api.openai.com/v1/responses` 或 DeepSeek `api.deepseek.com/chat/completions`；两个分支不会自动互换。B站 Cookie不作为模型请求字段发送 |
| ChatGPT登录 | OAuth授权码、PKCE、身份信息与令牌 | OpenAI官方登录服务；用户主动授权时。账户标识用于本机账户选择和缓存隔离 |
| YouTube缓存/检测 | 视频ID列表；检测时的视频ID和字幕 | 上游 `stop-the-slop-api.maurobum43.workers.dev`。YouTube页面浏览可能自动查询已有评分；检测代码路径会提交字幕 |
| DeepSeek账单同步 | 页面可见金额、请求数、Tokens、币种、Key筛选标签、时间范围、同步时间 | 仅本机 `127.0.0.1:17653`；首次点击同步按钮后，同一打开页面中筛选未变时自动更新。筛选变化需再次确认 |

浏览器按请求自然发送的IP、设备/请求头等由对应接收服务处理。不能因字段中没有 Cookie 或 `store:false` 就承诺服务端不留日志、不训练或零留存；请查看所用服务政策。上游服务的处理情况参见其 [隐私说明](https://mauropello.github.io/stop-the-slop/privacy.html)，本项目不能独立保证其实现。

## 本机保存

- 扩展存储：本机连接码、设置、B站视频ID/CID/标题及评分和模型/账户隔离标识、YouTube缓存。未设置统一自动过期，通常保留至手动清除或卸载扩展。
- 本地服务默认数据目录为**项目文件夹的上一级 `.local-data/`**，不是 `local-server` 内。可用 `BILI_SLOP_DATA_DIR` 改变实际位置；多个项目放在同一父目录时可能共享此目录。
- `accounts.json` 保存OAuth令牌和账户信息；`providers.json` 保存DeepSeek Key与设置；`connection.json` 保存配对码。文件不使用应用层加密。Unix文件权限0700/0600是代码请求的权限；Windows访问控制和备份安全需由系统管理。
- `usage.json` 保存本工具调用的时间、模型、账号/Key隔离标识、token、费用估计和状态。写入新事件时淘汰35天以前的事件，不是定时安全擦除。没有新的写入时旧文件可能继续存在。
- `official-usage.json` 保存按本机Key标识关联的最新可见账单摘要，包含Key标签和时间范围，没有独立到期删除机制。
- 服务端模型评分缓存在内存（最多200条）；任务队列也可能临时持有字幕。停止本地进程释放其内存引用，但不等于安全擦除。浏览器评分另行持久保存。
- 源码及发行ZIP不包含本机账户文件、Key、Cookie、连接码和用量记录。使用后的目录、系统/云备份以及浏览器配置可能包含这些数据，不要直接分享。

## 权限用途

`tabs`、`storage`、`scripting` 用于识别页面、存设置/缓存及字幕脚本；B站/hdslb域名用于视频和字幕；YouTube与上游Worker权限保留原有功能；回环地址用于连接本地检测服务；`platform.deepseek.com` 用于用户触发的可见账单同步。没有读取浏览器Cookie数据库的 `cookies` 权限，但访问B站接口仍可能携带浏览器登录态。

## 停止与清除

1. 在插件齿轮关闭自动检测；要确保不再发起请求，请禁用扩展并停止本地服务。关闭自动检测不保证取消已发出的模型调用，也不删除历史数据。
2. ChatGPT在本地设置页“退出当前账户”会删除该账户本机令牌并尝试远端撤销；失败会显示提示。请到ChatGPT账户设置检查并断开授权。其他已保存账户需分别退出；本机元数据仍可能保留。
3. DeepSeek在设置页勾选删除已保存Key并选回ChatGPT后保存；也可在DeepSeek后台撤销Key。删除本机副本不撤销服务端Key。
4. 若要完整清除，先退出账户、禁用扩展、停止本地进程，再删除实际数据目录中的本项目文件，并清除扩展存储或卸载扩展。**先确认是否有其他实例共享 `.local-data`，不要删除其他实例需要的数据。** 还需自行处理系统回收站、浏览器/云备份和下载副本。
5. 清除本地文件不删除已提交给模型商或上游服务的数据，也不撤销其已发生的计费。

## 自动连接

插件从扩展后台或扩展弹窗向本机 `/api/pair` 发起自动连接请求。服务仅接受浏览器扩展来源、JSON POST 与专用客户端请求头；普通网页来源和无来源请求无法获取连接凭据。连接凭据仍保存在本机 connection.json 和插件本机存储中，失效时插件自动重新获取。该接口不返回 ChatGPT OAuth 凭据或 DeepSeek Key；检测及用量接口继续要求连接凭据。本机设置页为自身的用量显示保留页面内凭据，不再向用户显示复制输入框。

## 本机服务控制（1.5.11）

扩展新增 nativeMessaging 权限；一次性安装程序仅在当前用户的 Chrome / Edge 本机消息主机配置（Windows 使用 HKCU 注册表）登记 com.stoptheslop.bilibili，并把程序复制到当前用户的应用数据目录。允许来源限定为本项目固定扩展标识；主机只接受 status、start、stop，不接受外部命令或任意路径。后台日志位于同一私有数据目录。停止按钮使用本机服务凭据请求结束服务，等待已发出的模型请求完成；它不声称撤销已经计费的请求。安装不会自动注册开机启动。/health 仅提供程序名、版本和停止状态，不包含账号或 Key。

## 插件内设置与封面显示（1.5.14）

服务配置与账户管理改由扩展界面调用认证的本机 API。用户输入的 DeepSeek Key 经本机回环接口提交至服务端保存；已保存 Key 不回传给插件，且输入框在保存后清空。插件存储只保留配对凭据、显示开关、自动检测偏好和检测缓存；OAuth 令牌仍仅由本机服务管理。账户列表仅返回邮箱/名称、公开客户端标识和登录状态，不返回令牌。

自动配对仅接受本项目固定扩展来源；普通网页及其他扩展不能获取配对凭据。登录请求使用短期、一次性的本机启动票据，OAuth 授权仍由 OpenAI 页面完成。旧 WebUI 的设置表单和模型测试接口已移除；/ 只显示迁移提示，OAuth 回调只显示授权完成提示。

封面光晕和百分比开关仅修改本机页面显示，不新增网络请求，也不改变缓存或评分规则。
