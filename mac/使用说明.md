# Stop the Slop for Browser 1.5.17 · mac 版

所有检测服务设置集成在浏览器插件中，日常不再使用本地 WebUI。服务后台运行；安装包仍为轻量包，不内置 Node.js。

## 安装 / 升级

1. 从 [Node.js 官网](https://nodejs.org/) 安装符合自己系统和处理器的 **Node.js 22 或更新版本**。
2. 下载 [最新 Release](https://github.com/LynkHu0/stop-the-slop-for-brower/releases/latest) 的 `-mac.zip`，完整解压并运行 `安装本机组件.command`。
3. 如果已使用 1.5.11 或封面光晕测试版，在浏览器扩展管理页对现有插件点击“重新加载”，然后刷新 B站即可。更早版本首次升级需移除旧扩展，加载安装程序打开的新版 extension 文件夹。
4. 打开插件，在“检测服务”区启动后台服务；在齿轮里的“服务与显示设置”中选择 ChatGPT 或 DeepSeek、模型、推理/思考强度和并发数，保存设置。
5. ChatGPT 可在插件中添加、切换和退出账户；登录时会打开 OpenAI 官方授权页，授权完成后回到插件即可。DeepSeek Key 在插件输入后仅提交至本机保存，不会回传已保存的 Key。

程序复制到 `~/Library/Application Support/StopTheSlop/app`，模型账户配置保留在 `~/Library/Application Support/StopTheSlop`。更新安装会等待已提交的旧版任务完成，再切换到新版后台服务。无需保留安装终端窗口。

## 插件内功能

- 后台服务启动 / 停止和运行状态。
- 检测服务选择、ChatGPT 模型与推理强度、DeepSeek 模型与思考模式/强度、并发1–100（默认15）。
- ChatGPT 账户添加、已有账户切换、退出；模型列表刷新；DeepSeek Key 保存或删除。
- 服务用量及官方用量入口。DeepSeek 官方账单同步仍需在其官方账单页操作。
- 自动检测开关。
- “显示封面百分比”与“显示封面颜色光晕”两个独立开关，默认都开启，已有结果立即更新显示，不重复调用模型。百分比开关只控制封面结果标签，不影响插件内仪表和“无文案”等状态提示。

光晕只包围封面，不包围标题/作者文字。低于40%绿色，40%～70%橙色，高于70%红色；无文案、排队、失败状态不发光。

原本 WebUI 的“浏览器插件自动连接”和“检查当前检测服务”已删除；不再提供手动模型测试按钮。全部操作只在插件弹窗完成，不提供独立设置标签页。

## 注意

停止时取消未开始的排队任务，等待已发出的模型请求完成后退出；已发出的请求可能已计费。不设置开机自启动。后台服务账号与插件缓存分别保存在本机，不要分享个人数据目录。检测只分析字幕，结果不能证明作者使用了 AI。

## 验证

完成隔离后端设置与授权边界检查、模拟卡片/弹窗检查及虚拟账户的浏览器设置界面检查，没有调用AI推理。真实 ChatGPT 授权和 Windows 实机升级仍需实际环境确认。

## 源码开发

在 local-server/ 运行 npm ci 安装源码依赖；发布包已合并依赖。native/ 为本机控制组件，package-release.py 用于制作无 Node.js 的轻量包。

1.5.17同步刷新当前账号缓存标识，禁止旧账号迟到结果重新上色。

## 简洁检测窗口与设置顺序（1.5.17）

打开插件默认只显示检测状态或检测结果。点击底部齿轮进入设置，点击返回箭头回到检测窗口；不会自动展开用量或服务设置，也不提供独立设置标签页。

设置从上到下：用量、显示封面百分比、显示封面颜色光晕、自动检测可见卡片、服务运行状态及开关、具体服务配置与账户管理。自动检测开关下面的长描述已删除。所有操作在插件弹窗中完成，不使用 WebUI。

检测字数：在插件设置的服务配置中填写，默认 1000，可设为 50–100000 的整数；只检测字幕开头，不足上限时全部检测。修改后保存设置，新旧字数的评分缓存会区分。

1.5.17：模型改为完整下拉选择，保留手动模型 ID；备用候选不代表账户已获权限。整合悬停动态预览封面标记和动态页检测修复。

播放页自动弹出检测报告默认开启，可在设置中关闭。字幕少于 50 字仍会检测，并标注“字幕较少”。已有用户的检测字数和并发设置保持不变。
